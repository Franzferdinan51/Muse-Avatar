# Muse avatar backup - 2026-10-13


Canonical copy: this repo (pushed 2026-10-13) - work on the avatar here.
The live firmware copy ships in Franzferdinan51/muse-gadget-206.
The watch character ("Muse") and everything that moves it, copied out of
muse-gadget-206 (branch museos-bringup, flash10 era) so the character can
be worked on separately from the firmware.

- avatar/muse_pixel.c - the whole character: procedural 64x64 pixel
  renderer. Palette + state colour schemes, body/face/eyes/mouth, aura,
  sparkles, expressions per mode, blink/breath/look animation, the
  RGB565 + RGB565A8 (alpha) strip scalers the LVGL decoder serves.
- muse_pixel.h - its header (poses, modes, render API).
- avatar/happy_anim.c/.h - the "happy" reaction animation.
- avatar/jollybot.gif - reference animation asset shipped in-tree.
- muse_ui.c - the frame loop that drives it: image_sync (pose/mode ->
  invalidate), the LVGL custom decoder (strip buffers, get_area), the
  canvas layout. The avatar only exists on screen through this file.

Design canon (owner, 2026-10-13): character sits directly on the page
backdrop (no black box - background cells are alpha-transparent), the
old gradient backdrop stays, no progress ring on the rectangular 206
layout, aura is a soft state-coloured halo (alpha 150/90), state word
and name never overlap.

## Juno (added 2026-10-14)

The second avatar in this repo: Juno, a black duck in a suit and
sunglasses, designed as a pixel sibling to Jollybot at Duckets'
request. Jollybot above is untouched. This repo is the avatar
storage - more avatars land here over time.

- avatar/juno_sprites.h - the character: 64x64 palette sprite maps
  (idle / blink / talk / happy), generated by tools/make_juno.py.
- juno_pixel.h + avatar/juno_pixel.c - the renderer: same pose
  input, grid, scale/alpha and bg-hook contract as muse_pixel, so a
  caller can swap faces without touching its frame loop. Blink and
  breath timing, talk/happy selection, state-coloured aura and the
  soft black floor shadow live here.
- avatar/juno_preview.png - contact sheet of the four poses.
- avatar/juno_idle.gif - animated idle preview (bob + blink).
- tools/make_juno.py - the design source: geometry, palette, the
  keying/shadow rules. Edit, re-run, and the sprites + previews
  regenerate.

Design notes: hard outline, background cells transparent (sits on
the backdrop, no box - same canon as Jollybot), sunglasses glints
double as the eyes, the yellow bill carries the expressions.
Watch integration (a third face in the muse-gadget-206 avatar
picker, next to the Juno GIF and the pixel Muse) is future work.

Design v2 (owner feedback, same night): the head is in 3/4 profile -
front-on, the bill stared the viewer down and read weird. Twelve
poses now, mirroring Jollybot's animation range: idle, blink,
look-left, look-right (idle gaze wander), listen (sound arcs),
think (thought dots), talk, happy, wave (raised wing + hearts,
the pet reaction), error (alert mark), sleep (Zzz), and boot -
wired to MUSE_MODE_BOOT with Jollybot's beats (rise-in over
0.6 s, lids shut until 0.9 s, aura fading in over 1.4 s; the
boot sprite is the shut-lid Juno ringed by wake-sparks). The
renderer picks them from the same pose struct Jollybot uses.
